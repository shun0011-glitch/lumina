LUMINA

美容室を想定して制作した、レスポンシブ対応のWebサイトです。

HTML・CSS・JavaScriptの基礎学習を目的に、デザインだけでなく、メニュー表示・予約フォーム・アニメーションなどのインタラクティブな機能も実装しました。

JavaScriptで学んだこと
変数

const と let を使ってデータを管理しました。

条件分岐

ifを使って、入力チェックやメニュー追加時の処理を制御しました。

関数

同じ処理を繰り返し書かないように、メニューカード生成や予約処理を関数としてまとめました。

配列・オブジェクト

メニュー情報を配列とオブジェクトで管理し、JavaScriptからHTMLを自動生成しています。

DOM操作

querySelector、createElement、classList、appendChild、removeなどを使い、HTMLをJavaScriptから操作しました。

イベント処理

addEventListenerを使い、クリック・スクロール・フォーム送信などのユーザー操作に応じて処理を実行しています。

Reservation Flow
予約フォームを開く
名前・メールアドレス・希望日などを入力
入力内容をチェック
予約内容を画面に表示
「予約を確定する」をクリック
予約完了メッセージを表示

※ 現在はJavaScriptによるデモ実装のため、実際に予約情報が店舗へ送信される機能はありません。

Responsive Design

画面幅768px以下ではスマートフォン向けのレイアウトに切り替わります。

Hero画像、メニューカード、予約フォーム、ナビゲーションなどをスマートフォンでも操作しやすいよう調整しました。

Purpose

このサイトは、Web制作の基礎からJavaScriptを使ったインタラクティブなサイト制作までを学習するために制作しました。

AIを活用しながらコードを書くだけでなく、「なぜこのコードが必要なのか」を理解することを意識して制作しています。
